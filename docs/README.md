# RWA Red-Team Lab Documentation

## Project role

RWA Red-Team Lab is an adversarial verification sandbox for deterministic checks against Real-World Asset evidence bundles.

## Documentation map

- [Root README](../README.md) — Gate 0 objective, security model and commands.
- [Project Status](PROJECT-STATUS.md) — factual maturity and current CI state.
- `verifier/` — deterministic verification code.
- `attacks/` — adversarial/tampering cases.
- `tests/` — automated checks.
- `assets/` — sample evidence bundles.

## Safety and scope

The repository tests evidence integrity. It does not establish legal title, identity, blockchain anchoring, financial issuance or regulatory compliance.

AI red-team automation remains outside Gate 0 until the deterministic baseline is green and reproducible.
